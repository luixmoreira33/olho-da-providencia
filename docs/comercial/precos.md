# Precificação Sugerida — Olho da Providência

## Modelos

### 1. Self-hosted Open Core (recomendado para início)
- Código aberto com funcionalidades principais.
- Licença comercial para multi-tenant, white-label, suporte e SSO avançado.
- Preço sugerido: **R$ 2.500 – 6.000 / mês** por cluster ou por pacote de apps.

### 2. Licença por número de aplicações
- Até 20 apps: R$ 1.800/mês
- Até 100 apps: R$ 4.500/mês
- Ilimitado: sob consulta

### 3. SaaS / Gerenciado
- Hospedagem + atualizações + suporte.
- Preço sugerido: **R$ 4.000 – 12.000 / mês** conforme volume.

### 4. Serviço de implantação
- Setup + mapeamento de apps + treinamento: **R$ 8.000 – 15.000** (projeto).

## Justificativa
- Redução estimada de 40–60% no tempo de diagnóstico.
- Menos licenças/telas abertas.
- Onboarding de devs mais rápido.
- Menos escalonamento ao SRE.
